MathSprout

In progress

A math practice app I'm building for my 4th grader, who is working through Singapore Math and Math Olympiad prep. Problems are checked by code, not AI. The AI tutor only asks hint questions and explains, so a wrong answer is never marked right.

  • Fraction, multiplication and division engines with unit and property-based tests
  • AI tutor that guides with questions, plus photo-to-text for homework problems
  • Family accounts with parent PIN, secured by database row-level security

Nuxt 4, Vue 3, TypeScript, Pinia, Vitest, Supabase, Claude API
