About

I'm a frontend engineer with 5 years of software engineering experience. For 3 years I built grocery e-commerce at Ahold Delhaize USA (Peapod) for brands like Stop & Shop, Food Lion, Giant Food, The GIANT Company and Hannaford: personalization, product search used by more than 1 million shoppers, and A/B tests in Vue 3, Nuxt and TypeScript. Before that I started my career at Accenture in Java and JavaScript.

I care about the parts users feel: pages that load quickly, forms that work with a keyboard, and error messages that say what to do next. I use AI tools like GitHub Copilot and Claude Code every day, and I'm learning where AI genuinely helps in a product and where plain, tested code is the better choice. MathSprout is that idea in practice.
