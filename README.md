# Portfolio

Personal portfolio site for Priyadharshini Sadhasivam. Plain HTML and CSS, no build step.

## Files

- `index.html`: all page content
- `styles.css`: styles (colors are at the top under `:root`)
- `favicon.svg`: tab icon
- `resume.pdf`: add your resume here; the resume buttons stay hidden until this file exists

## Preview locally

Open `index.html` in a browser, or run `npx serve .` and visit http://localhost:3000.

## Deploy

Hosted on Vercel, connected to GitHub. Every push to `main` redeploys automatically.
